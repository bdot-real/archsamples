Code Promotion to URC

A Gitea Actions pipeline that gates code on its way into the URC repository — the same safety, security and supply-chain checks whether the publisher is 3 Halves Labs, another agency, or URC itself. URC hosts none of it; 3HL runs the gate. AI assists the judgement calls, deterministic tooling is always the floor, and only a signed, attested build lands in the URC repo and deploys to its runtime — which can be hosted by URC or by 3HL.

The principleURC has to trust the code regardless of who published it. So the gate is the same for every publisher — 3HL, other agencies, or URC — AI can raise concern but never wave a build through, and no unsigned or critical-flagged commit lands in the URC repo.
