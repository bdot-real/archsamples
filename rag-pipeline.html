RAG Reference Pipeline

A production RAG pipeline as a schematic: an offline indexing path that turns sources into a governed vector index, and an online query path that retrieves, reranks, grounds and generates — with an evaluation loop closing back on the index. Tap any node.

indexing (offline) query (online) eval loop
TAP A NODE — the violet chain builds the index offline; the cyan chain answers a query online. They meet at Retrieve, where access controls filter what can be pulled. The dashed amber loop is evaluation feeding back to re-index and tune.
