ISO 20022 Payment Operations over MCP

A governed MCP server that exposes ISO 20022 payment capabilities as tools any MCP-compatible AI agent can call — Claude, GPT-4, Gemini. The agent can validate, build and query payment messages in natural language, but every action passes through a governance layer before execution. Payment operations run against Odoo.

The controlAn AI agent on a payment rail with no governance is a risk no regulated institution would accept. This server is the engineering answer: no single agent action can move money.
