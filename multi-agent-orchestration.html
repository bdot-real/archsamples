Multi-Agent Orchestration

A supervisor pattern as a hierarchy: one orchestrator owns the task and routes sub-tasks to specialist agents, who all draw on the same governed capability bus — tools, retrieval, memory and models. Guardrails wrap every model and tool call; a human approves the risky ones. Tap any node.
